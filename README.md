# Slay the Spire 2 - MoreEvent v0.1.9

这里是杀戮尖塔2-更多事件Mod的开源数据库。

目前mod还在增添内容阶段，尚未上传至steam创意工坊。

绝大部分图片类资源文件均通过ChatGPT生成，部分图片资源由多个来源获得或修改。

## Module Features

添加了 8 个新事件，添加了 5 张新卡牌，添加了 2 个新遗物。

与原版相似又不同的风格，旨在为游戏带来一定新鲜感，同时不破坏游戏的游玩逻辑。
